# Masood Ahmad — Portfolio

Personal portfolio site for Masood Ahmad, Senior Lead Data Engineer.

Built with [Next.js](https://nextjs.org) (App Router) and [Tailwind CSS](https://tailwindcss.com).

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Content

Resume/profile content lives in [`lib/data.ts`](lib/data.ts) — edit that file to update experience, projects, skills, or certifications without touching component code. The downloadable resume PDF is at `public/Masood_Ahmad_Resume.pdf`.

## Deployment

Deployed on [Vercel](https://vercel.com). Pushing to `main` triggers a new production deployment automatically once the project is connected.
